# Shopへのサインイン

アプリ内で支払うには、Shopのアカウントでサインインします。サインインはOAuthのdevice codeフローです。購入者は表示されたコードをShopの画面で承認し、このアプリはパスワードに触れません。トークンはサーバーだけが持ち、ブラウザには渡しません。

## 設定

`.env` に `SHOP_AUTH_CLIENT_ID` を書きます。値は、Shopの[認証ドキュメント](https://shop.dev/docs/authentication)にdevice flow用の公開クライアントとして載っているIDです。公開クライアントなのでシークレットは要りません。

ドキュメントには、他の人に配布するアプリは自分で登録したクライアントが必要だとも書かれています。このリポジトリは自分で動かす前提なので、IDはコードに埋め込まず `.env` で設定します。

要求するscopeは `openid email personal_agent`、resourceは `https://mcp.shop.com` です。サインインの承認画面には、デバイス名として `shop-agent` と表示されます。

## 試し方

1. `pnpm start` で起動します。
2. 画面右上の「Shopにサインイン」を押します。
3. 表示されたコードをShopの画面で承認します。
4. 承認されると「サインイン済み」の表示に変わります。

## 支払いについて

サインイン後の `complete_checkout` は、実際の購入になります。承認カードのボタンを押した場合だけ、1回実行されます。失敗や不確かな結果になっても再実行はせず、`get_checkout` で状態を確認します。
